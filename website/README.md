# Waitmesh website

Marketing site for [waitmesh.com](https://waitmesh.com). Visual system is a 1:1 port of [PG Circuit](https://pgcircuit.com) (Geist, accent `#0055ff`, hero-grid, marquee, site-shell, slash titles, terminal demo).

```bash
npm install
npm run dev    # http://localhost:3000
npm run build
```
